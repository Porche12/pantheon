# Публикация на GitHub Pages — пошагово

Сайт статический: HTML + CSS + JS, без сборки, без базы данных. Достаточно загрузить файлы в репозиторий.

## Вариант 1. Быстрый (весь сайт в корне репозитория)

1. Создайте репозиторий, например `pantheon` (публичный — на бесплатном плане Pages работает только с публичными репозиториями).
2. Загрузите в него **содержимое этой папки** (`index.html`, `404.html`, `.nojekyll`, `assets/`, `robots.txt`, `sitemap.xml`). Не саму папку `hosting`, а её содержимое.
3. В репозитории: **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main`, папка `/ (root)`
   - **Save**
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://porche12.github.io/pantheon/`

## Вариант 2. Через Git в терминале

```bash
cd hosting
git init
git add .
git commit -m "Pantheon: сайт арт-пространства"
git branch -M main
git remote add origin https://github.com/Porche12/pantheon.git
git push -u origin main
```
Затем включите Pages, как в шагах 3–4 выше.

## Вариант 3. Свой домен

1. Купите домен (например `pantheon39.ru`) и в настройках DNS создайте записи:
   - `A` для `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www` → `porche12.github.io`
2. В корне репозитория создайте файл `CNAME` (без расширения) с одной строкой — вашим доменом.
3. Settings → Pages → Custom domain → впишите домен, поставьте галочку **Enforce HTTPS**.

## Что важно знать

- **`.nojekyll`** — обязательный пустой файл в корне: без него GitHub Pages пытается обработать сайт сборщиком Jekyll и может проигнорировать часть файлов.
- Файл `pantheon-standalone.html` (сайт одним файлом) в пакет для хостинга не входит — он нужен только для отправки заказчице. Если хотите — положите его в репозиторий, он тоже откроется.
- **Заявки (CRM)** сохраняются в браузере посетителя/администратора (localStorage). GitHub Pages — только статика, серверного приёма заявок нет. Для приёма с разных устройств подключите внешний приёмник: Telegram-бот уже встроен (панель → Telegram), либо Google Sheets / Notion / Airtable — напишите, какой вариант нужен, и я подключу.
- Перед публикацией удалите демонстрационные заявки: панель → Telegram → «Убрать демо-заявки».
- Замените `USERNAME` в `sitemap.xml` на реальный адрес.

## Локальная проверка перед загрузкой

Просто откройте `index.html` двойным кликом — сайт работает и с диска (`file://`).
Либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Обновление сайта

```bash
git push
```
Pages обновится автоматически за 1–2 минуты.
